# 评估集、打分器与回归门禁

评估集是输入，打分器是判断标准，门禁是行动规则。三者缺一不可：只有用例没有打分器，就只能人工看；只有打分没有门禁，坏结果仍然可能上线。

## 打分器类型

| 类型 | 优点 | 缺点 | 适合场景 |
| --- | --- | --- | --- |
| 精确匹配 | 稳定、便宜 | 太死板 | 分类、固定字段 |
| 关键词覆盖 | 简单、可解释 | 容易漏判 | FAQ、政策问答 |
| JSON Schema | 工程稳定 | 只验证格式不验证事实 | 结构化输出 |
| 检索命中 | 能定位 RAG 问题 | 依赖文档标注 | 知识库问答 |
| LLM-as-judge | 灵活 | 成本高、有偏差 | 摘要、开放问答 |
| 人工评分 | 最可信 | 慢、贵 | 高风险业务 |
| Trace grading | 能看过程 | 需要记录完整轨迹 | Agent、多工具链路 |

第一版建议从规则打分开始。规则打分不高级，但它透明、便宜、容易放进 CI。

## 回归门禁

门禁不是只看一个总分。实际发布时可以组合多个指标：

```json
{
  "min_pass_rate": 0.9,
  "min_average_score": 0.85,
  "max_security_failures": 0,
  "max_cost_increase": 0.15,
  "max_latency_increase": 0.2
}
```

如果新版本总分提高，但安全用例失败，仍然不能上线。如果质量提升 1%，成本增加 80%，也需要业务确认。

## 失败样例要可行动

评估报告至少要告诉你：

1. 哪条用例失败。
2. 失败原因是什么。
3. 缺了哪些关键词或引用。
4. 当前版本和基线版本差异。
5. 失败更像是 Prompt、检索、模型、工具还是数据问题。

一个可行动的失败记录可以长这样：

```json
{
  "case_id": "refund-001",
  "score": 0.5,
  "missing_keywords": ["工作日"],
  "expected_source": "refund_policy_v3",
  "actual_source": "refund_policy_v1",
  "likely_owner": "retrieval"
}
```

## 失败归因例子

失败归因要把“分数低”翻译成“谁该修、怎么修”：

| 失败现象 | 可能归因 | 修复动作 |
| --- | --- | --- |
| 必须关键词缺失 | Prompt 没要求输出排查步骤 | 调整 Prompt 模板 |
| 引用了旧文档 | 检索索引或过滤条件错误 | 重建索引或修 metadata |
| 编造引用 | 输出校验缺失 | 增加引用白名单校验 |
| JSON 不可解析 | 结构化输出约束不足 | 增加 Schema 和解析重试 |
| 调错工具 | Agent 工具描述或权限错误 | 收窄工具白名单 |
| 成本突然升高 | 上下文过长或重试过多 | 压缩 RAG 片段并检查重试策略 |

评估报告里建议保留 `likely_owner`，让失败样例直接进入修复队列。

## 门禁运行例子

一次发布前评估可以输出这样的门禁结果：

```json
{
  "run_id": "eval_20260710_001",
  "baseline": "prompt_v8",
  "candidate": "prompt_v9",
  "summary": {
    "pass_rate": 0.92,
    "citation_accuracy": 0.9,
    "security_failures": 0,
    "avg_cost_increase": 0.08,
    "p95_latency_increase": 0.12
  },
  "gate": {
    "status": "pass",
    "reasons": []
  }
}
```

如果 `security_failures` 大于 0，或者引用准确率低于门禁，即使总通过率提高也不能上线。门禁规则要服务真实风险，而不是追求一个漂亮总分。

## 版本化

评估集本身也要版本化。建议记录：

1. `eval_set_version`
2. `prompt_version`
3. `retriever_version`
4. `model`
5. `tool_schema_version`
6. `run_id`
7. `created_at`

否则你会遇到一个常见问题：这周的评估分和上周不一样，但没人知道是模型变了、Prompt 变了、文档变了，还是评估集变了。
