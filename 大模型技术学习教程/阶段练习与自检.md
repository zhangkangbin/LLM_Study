# 阶段练习与自检

这个文件把 21 个阶段统一映射到同一个贯穿项目：

```text
Android 知识库助手 / Android 崩溃日志智能分析工具
```

每学完一个阶段，都建议完成一个小练习，再用自检问题判断是否可以进入下一阶段。

## 意图分类跨端自检

阶段 16 和 17 的联合练习不是复用一个手工挑选的旧模型，而是从样例数据训练一个新 artifact，再让 Python 和 Java 加载同一个文件、读取同一份 `intent_parity_cases.jsonl`。

仓库测试已经自动化这条路径：

```powershell
$env:PYTHONDONTWRITEBYTECODE = '1'
python '.\大模型技术学习教程\16-微调与模型定制\demo\tests\test_intent_classifier_demo.py' JavaIntentClassifierParityTest
```

可执行判定标准：

1. 命令退出码为 `0`，结果为 `OK`，且 Java 测试没有因缺少 `javac` 或 `java` 被 skip。
2. Python CLI 在临时目录训练新 artifact；Python 与 Java 后续都重新加载这同一个文件，不在比较时重新训练。
3. 两端对同一 parity case 的 `intent`、`reason` 和 candidate intent 顺序完全相同。
4. 每个 candidate probability、confidence 和 margin 的绝对误差不超过 `1e-9`。
5. 用例同时覆盖四个已知意图、`no_features`、`low_confidence`、`low_margin`、拉丁字母、数字和中英混合输入。

## 使用方式

1. 学完一个阶段，先做对应小练习。
2. 再回答自检问题，不要只看答案是否“像那么回事”。
3. 如果答不清，回到该阶段 README 和章节正文。
4. 如果能答清，把练习产物沉淀到综合项目文档里。
